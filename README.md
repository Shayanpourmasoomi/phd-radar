# PhD & Predoc Radar

ایجنت روزانه که آگهی‌های **PhD / Predoc / RA / Doctoral researcher** در **اروپا** را از چند سایت جمع می‌کند، با حوزه‌های اقتصاد شهری و محیط زیست فیلتر می‌کند و یک **صفحه‌ی وب** می‌سازد که روی آیپد/گوشی/لپ‌تاپ باز می‌شود. بدون API و بدون هزینه. **لپ‌تاپ لازم نیست**: روی سرورهای GitHub (Actions) هر روز خودش اجرا می‌شود.
